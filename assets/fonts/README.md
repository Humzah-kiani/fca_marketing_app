# Bundled fonts

These font files are bundled so `post_studio.py` can render each selectable
family without relying on fonts installed on the host machine.

- Poppins: SIL Open Font License 1.1; see `OFL-Poppins.txt`.
- Liberation Sans and Liberation Mono: SIL Open Font License 1.1; see `OFL-Liberation.txt`.
- TeX Gyre Pagella, Bonum, Adventor, Heros Condensed, Cursor, and Chorus:
  GUST Font License; see `GUST-Font-License.txt`.

The font files are matched by filename stem in `post_studio.py`.
